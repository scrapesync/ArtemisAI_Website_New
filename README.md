# Artemis — marketing site

The Artemis one-page marketing site. Static React, deployed to Netlify.

## Running it

```bash
npm install
npm run dev        # vite dev server
npm run build      # typecheck + production build to dist/
npm run preview    # serve the built output
npm run lint
```

## What this is

A rebuild of the design handoff in `docs/design-handoff/`, which contains the design tokens,
the prototype HTML for every section, and two briefs (`README.md` and `CLAUDE.md`) specifying
copy, motion timings and the accessibility contract.

The prototype HTML runs on a bespoke design-tool runtime (`support.js`, `<x-dc>` custom
elements) that is **not** ported. Those files are reference for structure, exact values and
copy only.

### Non-negotiables

Taken from `docs/design-handoff/CLAUDE.md`. These constrain every change:

- **Two colours.** Mint `#3BB98F` and warm white `#F6F3EE` on near-black. The only exception
  is platform brand marks at their true colours.
- **One easing family.** `--ease-reveal` for reveals, `--ease-out` for interactions. Reveal is
  always `opacity 0→1` + `translateY(18px)→0` over 700ms.
- **Contrast floor 7.2:1** for body and UI text. Mint is for headline-scale text, accents,
  labels and numbers — never long-form body copy.
- **44px minimum hit targets.**
- **`prefers-reduced-motion`** kills transitions, shows end states, suspends auto-advance.
- **Copy and mock numbers are verbatim.** Flag anything that looks wrong; don't fix it.

## Layout

```
docs/design-handoff/   the brief, tokens and prototype references
src/styles/tokens/     design tokens, copied verbatim from the handoff — the source of truth
src/styles/fonts.css   GENERATED by scripts/fetch-fonts.mjs
src/lib/               shared hooks (reveal, carousel, count-up, reduced motion)
src/components/        icons, platform marks, the device frame
src/sections/          one folder per section, each with its own CSS module
scripts/               font fetch, brand asset generation, screenshot harness
```

Styling is CSS Modules over the handoff's custom properties. There is no animation library —
every motion on the page is `opacity`/`transform` on CSS transitions and keyframes.

## Scripts

```bash
node scripts/fetch-fonts.mjs        # re-download webfonts, regenerate src/styles/fonts.css
node scripts/make-brand-assets.mjs  # regenerate favicons and the OG card from the roundel
node scripts/shoot.mjs --full       # screenshot dist/ at every breakpoint (needs a build first)
```

## Deployment

Netlify, configured by `netlify.toml`. Build `npm run build`, publish `dist`. No environment
variables or secrets.

The email capture posts to **Netlify Forms**. Netlify detects forms by parsing the built HTML,
which never sees a React-rendered form — so a hidden static twin named `trial-signup` lives in
`index.html`. Its field names must stay in sync with the real form.
